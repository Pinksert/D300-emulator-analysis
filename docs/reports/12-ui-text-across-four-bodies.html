先看这四台凭什么能放在一起比。它们的 B 段长度全部是 7,340,032 字节，末尾 2 字节的 CRC16/XMODEM（多项式 0x1021）全部与全段重算结果一致——也就是说，我下面每一个数字都是从完整、未被破坏、校验通过的固件里读出来的，不是从解密失败的残片里猜的。

四、功能差异：只信"整段一次都没出现"

先把口径说死，否则这张表会被读错。下面每个数字是"这个字符串在整个 B 段里出现的次数"。
· 非零只代表"固件里提到过这个词"，次数的多少受措辞、重复表、帮助正文的影响，不能当成功能的强弱。
· 只有 0 才是硬结论：说明这台机器的固件里，从菜单到帮助正文，一次都没出现过这个词。
· 每个 0 我都用"完整串 + 常见变体"双向复核过（比如"虚拟水平线"同时查 Virtual horizon 和 Virtual），避免"换了种说法"造成的假 0。

三条可以写进正文的结论：
  1. 虚拟水平线：D300 没有，D300S 有。"Virtual" 这个单词在 D300 的 B 段里出现 0 次，在 D300S 里 6 次、D3 里 8 次。这不是"措辞不同"能解释的。
  2. 短片：D300 没有，D300S 有，D90 也有。D300 和 D3 的 B 段里 "Movie" 出现 0 次。D300S 8 次、D90 5 次。
  3. D90 少了三样：间隔定时（0 次）、非 CPU 镜头设定（0 次）、虚拟水平线（0 次）。这三样 D300 / D300S / D3 都有。

五、一句话总结

四台共用同一套固件骨架（B 段同样 7,340,032 字节、同样的 CRC 校验方式、同样的 μITRON 与界面编码），但界面文字把它们的定位分得清清楚楚：

  • D300 与 D3 是同一档：都是 15 种语言、都没有短片；差别只在 D3 有虚拟水平线。
  • D300S 是四台里界面最厚的一台：文字量比 D300 多 40%，多了双卡槽、短片、虚拟水平线，语言从 15 涨到 17。
  • D90 是"同一代里被削过的那一台"：语言和 D300S 一样是 17 种、保留了短片，但丢掉了间隔定时、非 CPU 镜头设定和虚拟水平线。
